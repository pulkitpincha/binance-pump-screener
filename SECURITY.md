# Security Policy

## Supported versions

Security fixes are applied to the latest revision on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature on this repository
instead of opening a public issue. Include a concise reproduction and impact
assessment, but do not include exchange credentials, tokens, private trading
records, or other sensitive data.

This project consumes public market data and does not need Binance credentials.
If any version asks for an exchange API key, stop using it and report the issue.
